# Security Policy

## Reporting a Vulnerability

This repository is a curated list of links and does not ship application code that runs on end-user machines. However, we still take security seriously.

If you believe you have found a security issue in this repository or in the tooling it contains, please report it privately by opening a [security advisory](https://github.com/typescript-unofficial/awesome-typescript/security/advisories/new) rather than filing a public issue.

Please include:

- A description of the issue.
- The affected file or entry, if applicable.
- Steps to reproduce, if applicable.

We will acknowledge your report and work with you to resolve it.

## Scope

- The validation, generation, and link-checking tooling under `src/` and `scripts/`.
- The curated entries themselves (for example, a listed link that has become malicious or unsafe).

## Out of scope

- The security of third-party projects listed in the README. Those are the responsibility of their respective maintainers.
